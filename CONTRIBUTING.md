# Contributing / Contribuir / Contribuir

Fork the repository, create a descriptive branch, add sources and edition details, and open a pull request. Use stable lesson IDs across languages. Do not modify quoted confessional source text to match an interpretation. Label AI-assisted translations and request qualified human review before publication. Do not upload copyrighted materials without permission. Never commit learner personal information or secrets.

**Review checklist:** factual accuracy; Scripture citations; confessional accuracy; language quality; accessibility; provenance; license; safe external links.
