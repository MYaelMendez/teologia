# 🏵️ Biblioteca Luterana

**Preservar · Estudiar · Compartir · Enseñar.**

La Biblioteca Luterana es la colección bibliográfica multilingüe de TEOLOGIA · διδαχή, al servicio del Instituto Luterano Latinoamericano.

Incluye rutas de consulta para Escritura, confesiones luteranas, catecismos, historia, teología, liturgia, himnología y archivo latinoamericano. Cada recurso debe identificar autor, obra, edición, idioma, procedencia, derechos y estado de revisión.

No almacenamos automáticamente textos protegidos. Las traducciones, comentarios y materiales generados con IA se distinguen de las fuentes primarias y requieren revisión humana.
