**Un Evangelio · Muchas lenguas · Todas las generaciones.**

Repositorio educativo abierto del Instituto Luterano Latinoamericano.

**διδαχή** es la enseñanza. **ἐγχειρίδιον** es su manual portátil. **9:16** es nuestra interfaz contemporánea.
