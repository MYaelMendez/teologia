# ἐγχειρίδιον · Enchiridion

Luther's Small Catechism (1529) provides a historic model of portable, household-centered Christian teaching.

Planned units: Ten Commandments; Apostles' Creed; Lord's Prayer; Holy Baptism; Confession; Sacrament of the Altar; daily prayers and household instruction.

**Editorial rule:** preserve cited source editions separately from original instructional commentary. Translation rights and theological review must be checked before full texts are included.
